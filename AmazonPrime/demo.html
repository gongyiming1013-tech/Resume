Layer 3 · Dual Path
Fast lane and reasoning lane, side by side
"Don't make the keystroke wait for a thought."
Search Path ~200ms · p95

Hybrid retrieval (BM25 + dense embeddings) → fast ranker. Optimized for character-by-character latency on TV remotes.

Assistant Path 3–10s · streaming

LLM with tool use → catalog API → reasoning. Allowed to think. Streams tokens so the wait feels like work, not lag.

"No spoilers," "kid-safe," "under 90 min" as graph constraints. Solves: safety as architecture.

Diamond Excellence × AI-Native Tooling = 5–10× Velocity + E2E Innovation
i

Hire for the diamond, not the spike.

A 10/10 in one dimension with 2/10 elsewhere is not a pass. We need 4-of-6 over the bar. The org's ceiling is set by how round the average team member is — not how spiky the best one is.

ii

Velocity rituals over velocity rhetoric.

Weekly demo, biweekly ship, monthly retrospect. If anyone says "we're moving fast" without a demo, that's a tell. Rituals make velocity visible — and visible velocity is sustainable.

iii

AI-native operating model.

Every IC has a full agentic toolchain — Claude Code, Cursor, custom harnesses. Prompt engineering is a real skill, not a hobby. Eval-first development is the default, not the exception.

Bet 04 · Industry

PV has six structural moats. Search & Assistant is the org that turns one of them into a product.

Most of PV's moats are inherited givens — Prime bundle economics, MGM IP, Live Sports. We don't build them; we benefit from them. The cross-product entertainment graph is the moat we can ship — and the one no competitor can replicate, because no competitor owns Kindle, Audible, and Music.

★ Spotlight Moat · Buildable

Reading a book on Kindle changes what plays tonight on Prime Video.

Amazon is the only entertainment company with first-party signal across reading, listening, watching, and shopping in the same account. Today, those signals don't talk to each other. By Year 2, they do — gated by customer-controlled consent, off by default, visible in settings. Each cross-product step earns a measured 5–10× attribution lift.

"Netflix structurally cannot do this. Disney+ structurally cannot do this. This is the moat."
