Office Agent — Microsoft 365 Copilot (project codename "Societas")2025 – Present
Societas ML Team, Microsoft Redmond
  • Motivation & Goal: Build a multi-agent system for Microsoft 365 Copilot that delivers polished PowerPoint presentations, ready-to-use Word documents, and (soon) Excel spreadsheets — handling complex knowledge-work workflows end-to-end.
  • Architecture: Multi-agent orchestration engine on an open-source agent stack with Anthropic's Claude — a central planner agent coordinates tasks and synthesizes results; specialized agents for code, finance, search, etc. work in parallel; a secure tool layer integrates utilities and sandboxed environments. Adopted a code-first approach, letting the model write and execute code (e.g., MP3 transcription, PDF text extraction) instead of relying on task-specific tools, for greater flexibility and generalization.
  • Taste-Driven Development (TDD): pioneered a new generation paradigm — distilled "taste blueprints" from high-quality, in-house presentation/document samples; injected them into planning and execution to drive consistent design language. Built auto-theming (theme generated from content rather than picked from templates) and a content self-verification + iterative refinement loop. Output is HTML5-based slides with a converter to native PowerPoint.
  • Benchmark — GAIA & TDDEval (SOTA): achieved state-of-the-art on the public GAIA benchmark — L1 88.7 / L2 76.7 / L3 60.0, ahead of Genspark (87.8 / 72.7 / 58.8), Manus (86.5 / 70.1 / 57.7), and OpenAI Deep Research (74.3 / 69.1 / 42.3) per officially reported metrics. Also defined the in-house TDDEval benchmark for taste-driven generation across PowerPoint, Excel, and Word, scoring on Content Quality (grounding, relevance, completeness, structure, usability) and Taste Score (visual appeal, layout, typography, design consistency, asset curation).
  • AI-native execution: built and shipped the system as a fully AI-native team of 7, going from zero to SOTA in just 8 weeks, with 95%+ of code generated and reviewed via AI coding tools.
  • Deliveries: SOTA on GAIA across L1/L2/L3 difficulty tiers; Office Agent shipped as a multi-agent capability for Microsoft 365 Copilot. Microsoft Tech Community blog.
