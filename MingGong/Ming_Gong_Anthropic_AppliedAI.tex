\section*{Technical Highlights}

\subhead{Frontier Model Work}
\begin{itemize}
  \item \textbf{Distillation \& compression for production serving}: Authored novel model compression that powered the first BERT model deployed in Bing --- within 1 month of BERT open-source, zero added GPU cost; +3.0\% answer coverage, +5.0\% precision. Later built \textbf{Glow}, a distillation framework producing task-specific SLMs that replaced GPT-4-class models in production --- \textbf{first-token latency 20--30\,s $\to$ $\sim$5\,ms ($\sim$4000$\times$ reduction)}, scaled to 5--10\% of Bing global query coverage.
  \item \textbf{Universal multilingual model architecture}: Designed a cross-lingual model serving 100+ languages on $\sim$13\% of the GPU footprint a per-language approach would have required. Co-authored \textbf{Unicoder} (EMNLP/IJCNLP 2019), one of the earliest universal multilingual encoders, and \textbf{CodeBERT} (EMNLP Findings 2020, 3,000+ citations), the first pre-trained model for programming + natural languages.
  \item \textbf{LLM post-training \& SLM fine-tuning at production scale}: Established end-to-end post-training and fine-tuning framework for Copilot Search (multi-turn AI search vertical), including R1-distilled task-specific models; <5\,s first-token latency in production at consumer scale.
  \item \textbf{Retrieval architecture innovation}: Replaced industry-standard sliding-window passage indexing with runtime \textbf{query-dependent passage extraction} via GNN document modeling + multi-teacher distillation to 40\,ms latency. Held \textbf{\#1 on Google Natural Questions benchmark for $\sim$1 year}; architecture adopted across Bing QnA, Knowledge, People Also Ask, and Azure Custom QnA.
\end{itemize}
